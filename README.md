# 智感水界 - 多目标水体智能感知系统

## 项目简介

智感水界是一个全球领先的多目标水体智能感知系统，基于新型多功能复合SERS基底与微流控技术，搭载转盘式多芯片连续检测装置，实现水体污染物的精准检测，守护每一滴水的安全。

## 核心功能

### 1. 实时监测平台
- 多参数水质实时监测
- 数据可视化与趋势分析
- 异常检测与预警
- 历史数据查询与导出

### 2. AI智能分析
- 光谱数据分析
- 水质趋势预测
- 智能污染识别
- 分析报告生成

### 3. 线上商城
- 芯片产品展示与销售
- 智能芯片推荐系统（基于污染物选择）
- 购物车功能
- 产品详情查看

### 4. AI助手
- 百炼大模型集成
- 智能问答系统
- 技术咨询与支持
- 24/7在线服务

### 5. 联系我们
- 公司信息展示
- 联系方式
- 技术支持渠道
- 合作咨询

## 安装与运行

### 前置要求
- Python 3.6+
- 浏览器 (Chrome, Firefox, Edge等)

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd web
   ```

2. **安装依赖**
   ```bash
   pip install flask flask-cors python-dotenv
   ```

3. **配置环境变量**
   - 编辑 `.env` 文件，添加以下内容：
     ```
     API_KEY=your-api-key
     ```
   - 其中 `your-api-key` 是百炼大模型的API密钥

### 运行项目

1. **启动前端服务器**
   ```bash
   python -m http.server 8000
   ```

2. **启动API服务器**
   ```bash
   python api_server.py
   ```

3. **访问网站**
   - 打开浏览器，访问 http://localhost:8000

## 功能模块详解

### 实时监测平台
- **数据采集**：通过芯片传感器实时采集水质数据
- **数据处理**：AI模型分析处理原始数据
- **可视化展示**：图表展示水质参数变化趋势
- **异常检测**：自动识别异常数据并发出预警

### AI智能分析
- **光谱分析**：分析水体光谱数据，识别污染物
- **趋势预测**：基于历史数据预测水质变化趋势
- **智能识别**：自动识别污染物类型和浓度
- **报告生成**：生成详细的水质分析报告

### 线上商城
- **产品展示**：展示各种检测芯片和设备
- **智能推荐**：根据用户选择的污染物推荐合适的芯片
- **购物车**：方便用户管理选购的产品
- **产品详情**：查看芯片的详细技术参数

### AI助手
- **智能问答**：回答用户关于水质监测的问题
- **技术支持**：提供技术咨询和支持
- **百炼大模型**：集成阿里云百炼大模型，提供专业回答
- **本地降级**：当API不可用时，使用本地预设回答

## 部署说明

### 前端部署 (GitHub Pages)
1. 在GitHub上创建仓库
2. 推送代码到仓库
3. 进入仓库设置，启用GitHub Pages
4. 选择主分支和根目录
5. 等待部署完成，获取访问URL

### 后端API部署
1. 选择云服务提供商 (Heroku, Vercel, Render等)
2. 部署 `api_server.py` 到云服务
3. 配置环境变量 (API_KEY等)
4. 获取API服务URL
5. 修改前端代码中的API地址

## 注意事项

1. **API密钥安全**：不要在前端代码中直接暴露API密钥
2. **网络连接**：API调用需要稳定的网络连接
3. **浏览器兼容性**：建议使用现代浏览器访问
4. **性能优化**：大型数据可视化可能需要较高的浏览器性能
5. **部署环境**：生产环境建议使用专业的WSGI服务器
